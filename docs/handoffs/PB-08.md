# PB-08 — Deployment inspection
Owner A. Base ceecf07. Implementation: services/verifier/src/inspect/.

Reads the actual RiverMarket -> transparent proxy -> implementation/source path at a canonical block hash (EIP-1898), checks confirmations and rechecks that block before returning. The operator configures the RPC; users cannot submit endpoints. Calls have a total time budget, byte cap, count cap and bounded eth_call gas.

Recognizes exact compiled artificial market, source, V1/V2 implementation and OZ 5.4 ProxyAdmin runtimes. The proxy's immutable admin is substituted into the reviewed template and must equal its ERC-1967 admin slot. An unfamiliar runtime fails unsupported without assigning an upgrade owner. Approved implementation address AND runtime hash must match. Four exact configuration predicates, declared dependency path, unpaused state and nonzero owners are observed. An unmet condition names its responsible account. Multisig/governance classification and nonempty market selectors are explicitly unsupported in this slice.

Exports observed public code/storage for the exact finite supported family, for PB-09 offline execution. This is not a general account-state export, proof of RPC honesty, or security audit. The trusted compiled artifact set is part of verifier configuration. Build fixtures before startup. No signature or grant is issued here.

Validation: pnpm check; seven actual Anvil inspection cases cover version/config failure, actual path drift, historical reads after mutation, unsupported policy/authority/runtime and wrong chain/hash/missing historical block. Initial RED: module absent; one later test helper lacked explicit local wallet chain and was corrected to chain:null. Production never gets these unlocked local accounts.
