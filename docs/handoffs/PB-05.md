# PB-05 — Durable jobs and content-verified evidence

Implemented PostgreSQL tables/migration checksums, typed Drizzle document reads, immutable tenant-owned documents, transactional idempotency/quota locking, SKIP LOCKED claims, bounded leases/retries, stale-worker fencing and cancellation. A successful processing job is not a passing repair verdict.

ArtifactStore v1 has filesystem and S3-compatible adapters. Keys derive only from content hashes, writes are conditional/atomic, byte sizes are bounded, reads verify hashes, and job completion requires a retrievable matching artifact. A failed disk write cleans its temporary file. Filesystem mode is local only. The S3 tests use the actual AWS SDK against a local HTTP fixture; a hosted provider/account has not been exercised.

Validation: services/api/test/storage.integration.test.ts against actual disposable PostgreSQL tests concurrent duplicate enqueue, conflicting payloads, tenant isolation, exclusive claims, crash recovery, stale completion, missing/corrupt artifacts, retry exhaustion, success-error reset and bounded expiry cleanup. artifact-cleanup.test.ts injects a filesystem sync failure while using a real temporary directory. s3.integration.test.ts exercises conditional SDK writes and reads. Full results are in docs/evidence/backend-validation.md.
