# PB-07 artificial oracle test pack (review candidate)

The executable `OracleAdapterAssertions.sol` accepts caller-supplied deployment addresses and policy values. It has no fixture address exceptions, chain receipt signing, acceptance output, or hardcoded verdicts. `pack.json` identifies the required assertions. Parent review/policy approval is still required before a campaign pins the digest.

All three assertions must succeed: exact customer/source/max-age/decimal configuration and an unpaused market; a positive operation with an independently calculated nonzero expected value; and exact `StalePrice(uint256,uint256)` rejection of a positive stale price. A paused-market revert is deliberately not a stale-price pass. Missing ABI/data or an unrelated revert propagates as failure/unavailable evidence, never success. V1 is the known-bad baseline; V2 with six-decimal settings is still unsafe although its stale test succeeds.

PB-09 must run interventions on **separate isolated branches of the same source snapshot** and record them. For the artificial `TestPriceSource`, impersonate its owner on the fork to set the source price and timestamp. Restore the snapshot before each scenario. Do not send these interventions to a live source, normalize unsafe configuration, unpause a customer deployment to manufacture success, or infer acceptance from code identity alone. The source setter intentionally accepts zero/future/stale input to exercise the consumer; it is not a production oracle.

A typical fresh scenario is a 2,000 × 10^8 source price, timestamp equal to the snapshot, and 3 × 10^18 collateral. The independent expected quote is 6,000 × 10^18. Stale input uses a nonzero timestamp `snapshot.timestamp - expectedMaxAge - 1`; a snapshot too early to represent that is unavailable, not a pass. Source, expected max age, customer, amount and expected quote are policy/scenario inputs. The shared ABI lives in `packages/schema/src/fixture-abi.ts`; owner/paused reads are explicitly fixture-specific extensions. The inspector must additionally establish implementation code identity, dependency path, ERC-1967 slots and supplier ProxyAdmin ownership.

`fixtures/test/FixtureBehavior.t.sol` tests the pack against actual fixture contracts, including the bad baseline, repaired version, unsafe settings, paused market, ownership, initialization, malformed prices, upgrade state preservation, boundary age and quote units. It exercises real proxies without RPC mocks. The pack is not a generic vulnerability test or a reconstruction of Bonzo/Supra.

Digest rule: hash each distributed file's exact bytes with keccak256; sort entries in the fixed filename order `OracleAdapterAssertions.sol`, `pack.json`, `README.md`; encode `{schemaVersion:1,files:[{path,digest},...]}` with RFC 8785 canonical JSON; keccak256 of those index bytes is the test-pack digest. The local deployment exporter copies the actual pack, index and generated ABIs into its run directory. Local source changes necessarily change the digest. Compiler/library versions are pinned separately; a PB-09 runner must also record its executable/image identity. No test pass is inferred from this artifact's existence.
